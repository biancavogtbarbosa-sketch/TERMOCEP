# TERMOCEP

Projeto integrador desenvolvido por estudantes do 2º M - manhã do Colégio Estadual do Paraná.

## Descrição

O TERMOCEP apresenta uma solução conceitual de aquecimento sustentável e automação para a piscina térmica do Colégio Estadual do Paraná. O projeto integra conteúdos de Física, Óptica, Robótica, Programação e Acessibilidade Digital.
